# 小云桌宠 · 功能设计文档

> 以黄霄雲为原型的个人桌面宠物 · 完整功能设计
> 版本 v1.0 · 2026-09-02 · 个人粉丝向项目，非官方

---

## 1. 产品概述

### 1.1 定位

一只常驻桌面的云朵宠物"小云"，以歌手黄霄雲为性格原型：治愈黏人、元气碎碎念、爱吃面包、热爱唱歌。本地运行、数据不出本机，供粉丝日常陪伴与应援。

### 1.2 命名由来（三重闭环）

| 来源 | 说明 |
|---|---|
| 歌曲同名 | 《小云》收录于黄霄雲首张原创专辑《没语季节》（2024） |
| 谐音 | "小云" ≈ "霄雲"，粉丝向暗号 |
| 形象 | 项目已有原创云朵形象（软萌毛绒 3D 风，粉白配色） |

### 1.3 设计原则

1. **人格真实**：所有台词可回溯到她的公开语录存档（`data/weibo/xiaoyun-alt/posts.md`、skill 语录库），仿写台词显式标注"拟作"
2. **轻量常驻**：低 CPU/内存占用，不干扰正常工作
3. **渐进体验**：MVP 只做核心陪伴，后续模块按里程碑叠加

## 4. 详细功能设计

### 4.1 桌面常驻

| 功能 | 说明 |
|---|---|
| 无边框透明窗口 | 点击穿透（非角色区域）、置顶显示、不占任务栏 |
| 拖拽 | 按住角色拖动；松手后记住位置 |
| 多显示器 | 跟随主屏或手动指定屏幕 |
| 缩放 | 25%–150%，默认 64px 高（适配现有 128px 素材 2 倍渲染保证清晰） |
| 开机自启 | 系统登录项，可开关 |
| 显示层级 | 置顶 / 普通 / 全屏勿扰（检测到全屏应用时自动隐藏） |

**验收**：窗口透明无白边；拖拽流畅；重启后位置保持。

### 4.2 动画与状态机

#### 状态清单与素材映射

| 状态 | 触发 | 素材 | 现状 |
|---|---|---|---|
| 待机 idle | 默认 | `xiaoyun-front.png` | ✅ 已有 |
| 走动 walk | 随机游走/拖到屏幕边 | `xiaoyun-left.png`（左右镜像翻转） | ✅ 已有 |
| 背身转身 ignore | 连续点击 5 次（彩蛋：假装生气） | `xiaoyun-back.png` | ✅ 已有 |
| 开心 happy | 投喂/点歌/升级 | `xiaoyun-happy.png` | ✅ 已有 |
| 委屈 sad | 长时间未互动/演唱会日没票 | `xiaoyun-sad.png` | ✅ 已有 |
| 困倦 sleepy | 深夜/长时间无操作 | `xiaoyun-sleepy.png` | ✅ 已有 |
| 惊喜 surprised | 被戳/提醒触发/开抢倒计时 | `xiaoyun-surprised.png` | ✅ 已有 |
| 睡觉 sleep | 夜间 1:00–7:00 | 待新增（Zzz 素材，可用 sleepy 替代） | 🔲 |
| 唱歌 sing | 点歌/练声时刻 | 待新增（闭眼+音符） | 🔲 |
| 吃东西 eat | 投喂后 2 秒 | 待新增（抱面包） | 🔲 |

#### 状态机规则

- 状态优先级：特殊日期彩蛋 > 互动反应 > 提醒 > 时间状态 > idle
- 表情状态持续 3–5 秒后自动回落；sleep 状态点击可"戳醒"（进入 surprised → 抱怨台词）
- idle 每 30–120 秒随机切换小动作（眨眼缩放、左右摇摆、冒音符）

### 4.3 对话系统（核心）

#### 4.3.1 离线语录引擎（默认模式，零依赖）

**触发类型**：

| 类型 | 规则 | 示例 |
|---|---|---|
| 时间感知 | 按时段轮换（早安/午间/下午茶/晚安/深夜失眠梗） | 深夜 23:00 后 →"我还没睡着，求支招"（24-11-02） |
| 随机碎碎念 | 冷却 5–15 分钟，按权重随机 | "哦呼"（24-02-16） |
| 事件触发 | 互动/提醒/日期/系统事件映射 | 见附录 A |
| 关键词回应 | 气泡输入框内用户打字，命中关键词（面包/唱歌/演唱会/高考…） | "好听哭 真的 没吹牛"（24-05-13） |

**引擎规则**：
- 冷却与频率：全局台词间隔可调（默认最短 60s），重要事件不受冷却限制
- 去重：同一条台词 24h 内不重复；同一触发场景随机抽 3 条备选取最久未用的
- 台词库格式（`lines.json`，与爬虫存档字段对齐，便于从 posts.json 一键转换）：

```json
{
  "id": "wb-20240922-01",
  "text": "何须借光 你就是光",
  "source": "小号 2024-09-22",
  "type": "real",
  "triggers": ["keyword:光", "scene:encourage"],
  "weight": 1.0,
  "min_affinity": 0
}
```

- `type` 取值：`real`（真实语录，标出处）/ `adapted`（轻微删改）/ `original`（拟作）

#### 4.3.2 LLM 人格模式（可选，设置中开启）

```
System Prompt 结构：
[人设卡]     第 2 节内容（性格五维/称呼/口癖/禁忌）
[Few-shot]   10 条真实语录（时间+场景+原文），教语气
[知识库]     huangxiaoyun skill 摘要（生平/作品/语录，RAG 检索 top-k）
[约束]       ≤40 字；只用她的语气；不谈负面；不冒充本人；
             超出资料范围就说"这个我也不知道呀嘻嘻"
```

- 接入方式可配：本地 Ollama 或任意 OpenAI 兼容 API
- 离线语录始终作为 LLM 失败时的 fallback

**验收**：断网时对话功能不中断；LLM 输出符合口癖规范。

### 4.4 语音系统

| 层级 | 说明 |
|---|---|
| 文字气泡（默认） | 角色上方 3–6 秒，遵循台词长度 |
| TTS 朗读（可开关） | macOS 系统中文音色（如 Tingting），音量/语速可调；深夜时段自动静音 |
| live 音效彩蛋 | 从演唱会/live 视频截取 1–2 秒短句（欢呼、语气词），低概率触发（<5%），仅本机使用不外传 |

### 4.5 互动

| 交互 | 反应 |
|---|---|
| 单击 | 随机打招呼台词 + 轻微弹跳动画 |
| 双击 | 惊喜表情 + "要这个是吗？"（24-01-10） |
| 长按（摸头） | 开心表情眯眼 + 亲密度 +1 |
| 拖拽拎起 | 惊讶晃动，放下时"下次继续玩尬的"（24-09-08） |
| 投喂 | 拖面包/蛋糕/芝士/贵州粉/火锅图标到角色 → eat 动画 + happy；每种食物有专属台词（见附录） |
| 戳醒 | sleep 状态点击 → surprised →"蚊子你睡了吗？我痒的睡不着"（24-08-27） |
| 冷落 | 2 小时无互动 → sad + "很想念你们！！！"（24-11-03） |

### 4.6 好感度系统（魔星等级）

| 等级 | 名称 | 所需亲密度 | 解锁 |
|---|---|---|---|
| Lv1–2 | 新魔星 | 0–100 | 基础台词池 |
| Lv3–5 | 熟悉的魔星 | 100–500 | 深夜碎碎念、吃货台词 |
| Lv6–8 | 老魔星 | 500–1500 | "家人们"称呼、live 音效彩蛋 |
| Lv9–10 | 家人 | 1500+ | 九周年信长文案彩蛋、专属生日祝福 |

- 亲密度来源：每日签到 +5、互动 +1（每日上限 20）、投喂 +2、听歌 +3、连续 7 天额外 +20
- 降级保护：不因离线扣分；超过 7 天未见面触发"我很想你"回归台词

### 4.10 桌面小组件

- **云朵时钟**：hover 角色显示时间；整点报时（可关）
- **天气**：角色状态联动天气——雨天角色打伞/变灰，晴天"我又成功把太阳带过来了"（24-07-13）
- 数据源：系统定位 + 免费天气 API，本地缓存

### 4.11 设置面板

台词频率 / TTS 开关与音色 / 音效音量 / 自启动 / 缩放 / LLM 模式配置（端点+密钥）/ 语录库管理（启停分类、从 posts.json 导入新语录、查看"拟作"占比）/ 好感度与统计（互动次数、陪伴天数）/ 重置。

### 4.12 数据与扩展

- 数据目录：`~/.xiaoyun-pet/`（config.json、affinity.json、lines.json、user_lines.json）
- 语词库可直接由 `scripts/weibo_crawler.py` 产出的 posts.json 转换（复用字段 text/created_at）
- 事件脚本：JSON 声明式定义"日期/条件 → 状态+台词+动画"，无需改代码
- 皮肤包：后续支持导入其他角色素材目录（沿用现有素材规格）

## 7. 技术选型与架构

**推荐：Tauri 2 + Web 前端**（安装包 <10MB、内存占用低；备选 Electron 生态更熟）

```
┌─ Tauri 主进程 (Rust)
│   窗口管理（透明/置顶/穿透/多屏）、自启动、系统托盘、文件扫描
├─ 渲染层 (WebView: HTML/CSS/TS)
│   角色渲染（PNG 精灵 + CSS 变换动画）、气泡 UI、设置面板
├─ 状态机 (TS)

    ~/.xiaoyun-pet/ 配置、好感度、台词库（可从 posts.json 转换）
```
