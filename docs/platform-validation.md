# 双平台验收

## 自动验证

运行：`cd app && npm test`、`cd src-tauri && cargo test --locked`、`npm run build -- --ci`（最后一条在 app 目录）。

GitHub Actions 的 `Desktop compatibility` 分别使用 macOS / Windows 原生 runner。Windows 测试会实际调用 System.Speech，将 Unicode 文本合成为 WAV 并通过 rodio 解码；无需音频输出设备。构建后 smoke 脚本启动 release 可执行文件并检查窗口样式，上传桌面截图及日志。

这些检查会报告失败，不会把没有音色、编译错误或应用崩溃当作通过。

## Windows / macOS 桌面验收清单

以下项目不能仅凭构建成功确认；在可用的真实桌面或虚拟机中逐项操作并记录结果。

- [ ] 安装/启动/退出：只显示一只小云和一个托盘图标；无普通任务栏/Dock 图标。
- [ ] 窗口透明、无边框、置顶；截图中没有黑色/白色背景。
- [ ] 点击角色有反应；透明区域可以点击下方桌面；右键菜单可打开。
- [ ] 拖拽期间不会穿透；放下后恢复逐像素命中；托盘“整窗接收鼠标”可切换。
- [ ] 分别在 100%/125%/150%/200% 缩放下检查点击位置；跨不同缩放的显示器拖拽、负坐标副屏和重启位置恢复。
- [ ] 设置、聊天、历史窗口可打开和关闭；目录选择器可用；中文目录下的皮肤和音乐可加载。
- [ ] 系统朗读（中文音色）、自定义 WAV 接口及音效均有声音；音量、停止、连续触发和深夜静音正常。
- [ ] 本地 MP3/M4A/WAV 歌曲可播放并触发唱歌动画（格式支持取决于系统 WebView 的解码能力）。
- [ ] 断网/错误音色端点时，界面响应，试听提示失败；不会播放上一次的旧语音。
- [ ] Windows 网络请求及朗读过程中无控制台黑框闪烁。
- [ ] 好感度、设置、聊天数据重启后保留；从 macOS 复制配置到 Windows 后重新选择本机路径。
- [ ] 开机自启开关生效；休眠唤醒后提醒和鼠标交互恢复；卸载正常。
